# Git & GitHub

This repository contains my personal notes on **Git** and **GitHub**, covering
basics, commands, workflows, common mistakes, and recovery techniques.

It is intended for:
- Beginners learning Git & GitHub
- Quick revision / reference

---

## Repository Structure

```
.
├── _git.md             # Detailed Git commands & concepts
├── _git-basics.md      # Git basics and core concepts
├── _github.md          # GitHub & remote repository workflows
├── _git-mistakes.md    # Common Git mistakes & recovery
```

- Repository initialization
- Status, add, commit
- Logs and HEAD

### Git Advanced Commands
- Reset (soft / mixed / hard)
- Restore
- Amend commits
- Reflog & recovery
- Stash
- Revert

### Branching & Merging
- Branch creation & deletion
- Merge & rebase
- Conflict resolution
- Detached HEAD

### GitHub / Remote Repositories
- Connecting local repo to GitHub
- Push, pull, fetch
- Remote branches
- Uploading an existing project
- Branch management on remote

### Common Mistakes & Fixes
- Committing to wrong branch
- Wrong commit messages
- Lost commits
- Merge conflicts
- Safe undo for pushed commits
